Menus that fit every screen

Today you fix a real problem: a canteen website that breaks on a phone. You will learn responsive design one idea at a time, try it yourself, check your work, and then use it on your own client's site.

Gagné's first event gains attention. A real, local, slightly funny problem makes students care before any CSS appears. The vote is emotional engagement: they feel the customer's frustration, so the fix matters to them.

3
Recall prior learning

Warm-up: what do you remember from Week 4?

1. Which property adds space inside a box, between its content and its border?

2. With display: flex, items line up in which direction by default?

3. Which of these widths can shrink to fit a small screen?

Designer's note

Recall connects new learning to what students already know. Question 3 quietly sets up today's key idea, so the content in event 4 feels like the next step, not a new topic.

4
Present the content

Three ideas, one at a time

Design for the smallest screen first. On a phone, everything sits in one column. Nothing has a fixed width wider than the screen, and images shrink to fit. Then you add columns as the screen gets wider.

.menu {
  max-width: 1000px;   /* never wider than this… */
  width: 100%;         /* …but it can shrink */
  margin: 0 auto;
}
img { max-width: 100%; }

Let the grid decide how many columns fit. Instead of saying "3 columns", say "as many columns as fit, each at least 220px wide". The browser does the rest.

.menu {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  gap: 16px;
}

Change the layout at a breakpoint. A media query applies CSS only when the screen is at least a certain width. Mobile-first means you use min-width: small screens get the base CSS, bigger screens get extras.

/* phones: one column (the base CSS) */
@media (min-width: 700px) {
  .header { display: flex; justify-content: space-between; }
  h1 { font-size: 40px; }
}
Designer's note

Content is chunked into three short ideas, each with one code example. Students see one idea at a time instead of a long lecture, which keeps the cognitive load low before they try it.

5
Guide the learning

Watch the menu get fixed, step by step

Click through the four steps, then drag the slider to change the screen width. Watch what each step changes.

Designer's note

Guidance means worked examples with cues. Each step changes one thing, and the resizable preview makes the effect visible immediately. This is the "I do, we do" moment before students work alone.

6
Let them practice

Your turn: fix the canteen menu

  1. Make the menu shrink: replace the fixed width with max-width and width: 100%.
  2. Turn the cards into a flexible grid with repeat(auto-fit, minmax(…)).
  3. Add one @media (min-width: …) rule that improves the laptop layout.
  4. Make the text readable on a phone (16px or more).

Your work is saved in this browser.
Designer's note

Practice means doing it, not watching it. The task mirrors the guided demo but with a new page, so students must apply the ideas themselves. The live preview lets them test at three screen sizes as they go.

    9
    Help them transfer

    Now use it on your real client's site

    Course challenge · Module 3 milestone

    Make your client's page work on the phone their customers actually use.

    Take the local business you're building a site for (a sari-sari store, a carinderia, a parish office, a small clinic). Open their current page, or your draft, on a real phone. Then apply today's three ideas.

    • Test on a real phone and take a before screenshot.
    • Apply mobile-first, a flexible grid, and one media query.
    • Ask the client (or a family member) to order or find something on the phone. Watch them.
    • Bring your before and after screenshots to Week 6.

    Exit ticket. Answer in one or two sentences each.

    Designer's note

    Transfer means using the skill somewhere new. The challenge moves the lesson from a practice canteen page to a real client with real customers. That's challenge-based learning, and it keeps the course outcome, "create a site for a real client", in view every week.
